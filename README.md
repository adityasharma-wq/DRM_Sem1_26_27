## 2. Getting the material

Pick whichever option you're comfortable with.

### Option A — Google Colab (nothing to install)

Open any notebook directly in Colab by replacing the GitHub URL prefix:

```
https://colab.research.google.com/github/<username>/<repo>/blob/main/Lab01_<Topic>/Lab01_Example.ipynb
```

Or click the **Open in Colab** badge at the top of each lab's README.
Remember to `File → Save a copy in Drive` before you start editing.

### Option B — Download a single lab

On the GitHub page, open the notebook → click the **Download raw file** icon.
Also download anything inside that lab's `data/` folder and keep the same
relative folder structure, or the file paths in the notebook will break.

### Option C — Clone the repository (recommended)

```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>
```

To pull new labs as they are posted:

```bash
git pull
```

If `git pull` complains that your local changes would be overwritten, it's
because you edited the original notebooks. Always work on a **copy**
(`Lab03_Sheet_2023A7PS0123P.ipynb`) and leave the originals untouched.

## 3. Setting up your environment (local)

Anaconda is the simplest route — it ships Python, Jupyter, and most of what we need.

1. Install <Anaconda / Miniconda> from https://www.anaconda.com/download
2. Create the course environment:

```bash
conda create -n drm python=3.11
conda activate drm
pip install -r requirements.txt
```

3. Launch Jupyter:

```bash
jupyter notebook        # or: jupyter lab
```

**Core packages used in this course:** `numpy`, `pandas`, `matplotlib`,
`seaborn`, `scipy`, `scikit-learn`, `statsmodels`, `jupyter`
<add/remove as per your syllabus>

Before your first lab, run `Lab00_Setup/environment_check.ipynb` — it verifies
every package is importable and prints the versions.

## 4. Submitting a lab sheet

All graded submissions go to **Nalanda**, *not* to GitHub. Do not email
notebooks and do not open pull requests on this repository.

**Steps:**

1. Download the lab sheet from this repo (or open it in Colab).
2. Solve it. Write your code in the cells marked
   `# ---- YOUR CODE HERE ----` and your reasoning in the markdown cells
   marked `**Your answer:**`.
3. **Run all cells top to bottom** (`Kernel → Restart & Run All`) and confirm
   there are no errors and that every output is visible in the saved file.
   *A notebook submitted with empty outputs loses marks.*
4. Save the file with this exact name:

   ```
   DRM_Lab<NN>_<CampusID>.ipynb

   e.g.  DRM_Lab03_2023A7PS0123P.ipynb
   ```

5. Upload to the corresponding assignment on Nalanda before the deadline.

**Also check:**

- Your **name, campus ID, and lab number** are filled in the first markdown cell.
- If the notebook writes out plots or a CSV, those are generated by the code —
  don't paste screenshots.
- Submit the `.ipynb` file itself. Also attach a PDF export if you want one.
- If a lab needs extra files, zip them as `DRM_Lab<NN>_<CampusID>.zip`.

## 7. Troubleshooting

**`FileNotFoundError` when loading a dataset** — your notebook isn't in the
folder it expects. Keep the notebook inside its lab folder alongside `data/`,
or update the path in the loading cell.

**`ModuleNotFoundError`** — the package isn't installed in the kernel you're
running. Activate the `drm` environment before launching Jupyter, or run
`!pip install <package>` in a Colab cell.

**Notebook won't open / shows "Unreadable Notebook"** — you probably saved an
HTML page instead of the raw file. Re-download using the *raw* link.

**Colab session reset and I lost my work** — Colab discards runtimes after
inactivity. Save to Drive early and often.
